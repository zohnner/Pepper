# Visual Prompt Template

Every prompt is built from these blocks. Copy the locked blocks verbatim; only the shot description changes.

## Locked style block (every prompt)
"Stylized 3D animation, storybook noir. Warm lantern amber light against deep blue-green shadow. Wet brick, reflective cobblestones, cinematic, highly detailed."

## Locked Pepper block (every prompt containing Pepper)
"small grey tabby cat with a torn left ear, a crooked white stripe down her nose, and oversized green eyes, thin street-cat build"

## Shot block (changes per shot)
One clear sentence: character + action + environment + camera.
Example: "Pepper crouched at the edge of a canal in the flood tunnels, staring at her rippled reflection, slow push-in."

## Full prompt assembly
[Shot block]. [Pepper block if present]. [Style block].

## Animation direction (for image-to-video)
One line: camera move + subject motion + duration feel.
Example: "Slow push-in, lantern flames flicker, water ripples, Pepper's ears twitch once."
