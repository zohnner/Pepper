# Upgrade Path — free now, capable later

The pipeline has fixed stages. Free tools fill them today; paid tools slot into the same stages later with zero restructuring. Upgrade a stage only when it becomes the bottleneck — never preemptively.

## The stages (these never change)

Write → Stills → Clips → Voice → Edit → Post → Review

## Swap-in map

| Stage | Free now | Paid later | Upgrade trigger |
|-------|----------|------------|-----------------|
| Stills | Built-in image generation | Midjourney / Flux Pro | Character drift costs more regen time than a subscription |
| Clips | Built-in image-to-video | fal.ai: Kling v3 Std $0.084/s, LTX-2.3 Fast $0.04/s, H3 Max $0.08/s w/ 5 free gens/day | Need longer clips or full character motion |
| Voice | Built-in TTS | ElevenLabs Starter $6/mo (30k chars = full month, commercial) | Voice quality or emotional range limits episodes |
| Edit | CapCut free | CapCut Pro / Premiere | Template needs pro transitions, auto-captions styling |
| Music | Free libraries (below) | Epidemic Sound | Copyright-safe trending catalog matters |
| Post | Native schedulers | Metricool / Buffer | Managing 3+ platforms manually eats the morning |
| Analytics | Native insights | Metricool / platform APIs | Weekly review needs cross-platform numbers in one place |

## Rules

1. One stage upgrades at a time. Measure the effect for two weeks before touching the next.
2. A paid tool must save at least 2 hours/week or visibly lift retention to earn its slot.
3. The bible, templates, and continuity log never change regardless of tooling — canon is tool-agnostic.
