# Posting Checklist

Run per episode, per platform. Two slots a day: morning + evening.

## Before scheduling

- [ ] master.mp4 is clean — no TikTok/CapCut watermark burned in
- [ ] Captions are burned in and readable (test on a phone screen, not desktop)
- [ ] Cover frame set with cover text from meta.md (4 words max)
- [ ] Cover text clears platform UI: keep clear of the right rail (like/comment buttons) and bottom caption zone
- [ ] Audio: voiceover clear, music bed low under narration, silent for the lift shot
- [ ] Caption + hashtags copied from meta.md, open loop intact

## Posting

- [ ] Upload NATIVELY to each platform (never re-upload a TikTok-watermarked file to Reels/Shorts)
- [ ] TikTok: schedule via TikTok scheduler, pin the series explainer comment on ep001
- [ ] Meta: schedule Reels via Meta Business Suite for Facebook + Instagram
- [ ] Both daily slots filled before 8 AM

## After posting

- [ ] Mark TRACKER.md: Scheduled → Posted AM/PM
- [ ] Reply to early comments within the first hour (algorithm fuel)
- [ ] Log any standout comment as a future episode idea
