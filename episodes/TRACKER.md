## Stage definitions

- **Script:** script.md + prompts.md + voiceover.txt + meta.md written, continuity log updated
- **Stills:** all scene stills generated, Pepper's three marks verified on every frame she's in
- **Clips:** every still animated, motion matches the animation direction
- **Voice:** voiceover.mp3 generated in Pepper's locked voice, pacing checked against the edit
- **Edit:** master.mp4 assembled in CapCut template, captions burned in, cover frame set
- **Scheduled:** native uploads scheduled for both daily slots, no watermarks
